# ZUBAIR. | Recursive 3D Portfolio Architecture

A high-performance, aesthetically-driven portfolio built with a focus on "Cybercore" minimalism and technical precision. This project serves as a digital archive for **Zubair Shaikh**, showcasing his expertise in Syntax Engineering, Cyber Operations, and Kinetic Intelligence (Machine Learning).

## 🛠 Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics:** [Spline](https://spline.design/)
- **Styling:** [Tailwind CSS 4.0](https://tailwindcss.com/)
- **Iconography:** [Lucide React](https://lucide.dev/)

## 🏗 Key Features

- **Recursive Hero Interface:** High-contrast typography with interactive tilt effects.
- **Cyber Arsenal:** A categorized display of technical skills and high-level proficiency mapping.
- **Project Archives:** Direct links to production-grade repositories including ML models, trading bots, and security labs.
- **Fragment Gallery:** A grayscale-to-color visual archive of personal and academic milestones.
- **Sync Contact:** Direct Gmail and LinkedIn integration with custom mail-to handling.

## 🚀 Local Installation Guide

Follow these steps to run this project on your local machine after extracting the ZIP folder.

### 1. Prerequisites
Ensure you have **Node.js** installed (Version 20 or higher recommended).
- [Download Node.js](https://nodejs.org/)

### 2. Open Terminal
Open your terminal (CMD, PowerShell, or Bash) and navigate to the extracted folder:
```bash
cd path/to/your/extracted-folder
```

### 3. Install Dependencies
Run the following command to download all necessary libraries:
```bash
npm install
```

### 4. Launch Development Server
Start the local server:
```bash
npm run dev
```

### 5. Access the Project
Once the command finishes, open your browser and go to:
**`http://localhost:3000`**

## 📁 Project Structure

- `src/App.tsx`: The heart of the application containing all sections and logic.
- `src/index.css`: Global styles and Tailwind configuration.
- `src/main.tsx`: Entry point for the React application.
- `public/`: Assets targeted for static serving.

## ⚙️ Configuration Notes

- **Port:** The project is configured to run on port `3000`. You can change this in `package.json` under the `dev` script.
- **Icons:** All icons utilize the `lucide-react` library.
- **3D Scenes:** The background interactives are hosted on Spline. To update them, swap the URL in the `LazySpline` component calls.
